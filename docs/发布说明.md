# Codex 额度监控 0.28
2026-11-21 · Windows x64 公开测试版

## 更新内容
- 任务栏背景采用逐像素透明，文字固定白色，字体为 10 号常规体；文字预留空间同步调整。
- 修复透明区域漏掉鼠标事件的路径：整条文字区域接收鼠标事件，打开弹窗不依赖 50 毫秒轮询。
- 保留每 100 毫秒辅助判断收起，并补充文字与弹窗间的衔接区域。
- 监听窗口切换和任务栏层级变化，重新调整文字层的置顶顺序。
- 移除简约卡片模式；旧配置自动迁移到任务栏模式。
- 加入跟随 Codex 桌面程序启停的助手。主程序名为“额度监控.exe”，两个入口使用同款图标。

## 下载与使用
提供完整免安装 ZIP 和当前用户安装版 EXE。升级前先退出旧程序，便携版完整解压到新目录。
安装版默认不自动启动、不启用开机启动；可从开始菜单打开“跟随 Codex 启停”来启用联动。
跟随助手轻量常驻，主程序在 Codex 未打开时不运行。完全退出 Codex 后约 6 秒关闭监控，最小化不关闭。
需要官方 Codex、自己的登录状态和 .NET Framework 4.6.1+。
