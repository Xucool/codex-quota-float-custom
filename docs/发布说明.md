# 发布说明

Codex 额度监控（CodexQuotaFloatCustom） · `0.2.5-custom.3`

版本说明日期：2026-11-02。状态：公开测试版（Pre-release），标签 `v0.2.5-custom.3`。

## 本版内容

- 提供简约卡片、百分比悬停、任务栏固定显示三种模式，移除旧的其他布局选项。
- 额度页显示 5 小时及周额度、各自重置时刻、重置卡数量与剩余有效时间；偏好设置独立为第二页。
- 任务栏文字紧邻隐藏图标箭头左侧，悬停查看额度，左键选择返回悬浮窗，右键选择退出应用。
- 保留退出时的模式和偏好，可自行开启开机启动。
- 增加与界面配套的宠物显示开关；开关先响应，后台再完成显示或隐藏，不阻塞点击反馈。
- 重置卡列表最多显示三行，更多条目可滚动查看；支持向本机 Codex 发出真实使用请求，并显示返回结果。

## 安装方式

安装版为 `CodexQuotaFloatCustom-0.2.5-custom.3-Windows-x64-Setup.exe`。安装程序配置为当前 Windows 用户安装，不要求管理员权限，包含桌面快捷方式和卸载入口；安装结束不自动打开程序，也不默认开启开机启动。当前已完成编译，尚未实际执行安装验证。

另有 `CodexQuotaFloatCustom-0.2.5-custom.3-Windows-x64-Portable.zip`。完整解压后打开 `CodexQuotaFloatCustom.exe`，不能只复制主程序。两种程序及 `SHA256SUMS.txt` 均从 [本版本发行页](https://github.com/Xucool/codex-quota-float-custom/releases/tag/v0.2.5-custom.3) 下载。

普通使用者无需 Node.js 或 SDK。系统需具备 .NET Framework 4.6.1 或更高版本，并安装官方 Codex、登录自己的 ChatGPT 账户。仅 API Key 登录可能没有可显示的套餐额度。

安装包未做代码签名，Windows 可能提示未知发布者；只在确认来源可信后运行，不需要关闭安全功能。
