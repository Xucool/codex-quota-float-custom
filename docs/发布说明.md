# 发布说明

Codex 额度监控 v0.2.6 · Windows x64 公开测试版

发布日期：2026-11-13。基于本地当前版本制作，前一公开版本为 v0.2.5-custom.3。

## 本次更新

- 更新偏好设置下拉菜单，支持选择后关闭、失焦关闭和 Esc 关闭。
- 调整重置时间居中显示、窗口样式行定位与重置卡区域排版。
- 重置卡条目减少时，任务栏和百分比弹窗随内容收缩。
- 保留简约卡片、百分比悬停、任务栏固定显示三种模式。

## 下载与使用

[安装版](https://github.com/Xucool/codex-quota-float-custom/releases/download/v0.2.6/CodexQuotaFloatCustom-0.2.6-Windows-x64-Setup.exe) · [便携版](https://github.com/Xucool/codex-quota-float-custom/releases/download/v0.2.6/CodexQuotaFloatCustom-0.2.6-Windows-x64-Portable.zip)

安装前先退出旧程序。便携版请完整解压到新目录。安装程序面向当前 Windows 用户，安装后不自动启动。需要官方 Codex 及自己的登录状态、.NET Framework 4.6.1 或以上，无需 Node.js。
